# CodeAlpha - SQL Injection Security

## Project Overview

This project demonstrates security techniques for protecting user data against SQL injection attacks as part of the CodeAlpha Cloud Computing Internship.

The system uses AES-256 encryption, parameterized SQL queries, SQL injection detection, and secure user authentication.

## Key Features

- AES-256 encryption for sensitive information
- Secure parameterized SQL queries
- SQL injection attempt detection
- Double-layer security verification
- Secure user authentication
- SQLite database integration

## Technologies Used

- Python
- SQLite
- Cryptography
- Google Colab

## Project Modules

1. AES-256 Encryption
2. Data Decryption
3. Secure SQLite Database
4. Parameterized SQL Query
5. SQL Injection Testing
6. Double-Layer Security Verification
7. Final Security Verification

## Security Features

### AES-256 Encryption

Sensitive user information is encrypted using AES-256 encryption.

### Parameterized SQL Queries

Parameterized queries are used to prevent malicious SQL input from being directly executed as part of a query.

### SQL Injection Detection

The system tests suspicious SQL injection patterns and prevents unauthorized access.

### Double-Layer Security

The authentication process combines credential verification with suspicious-input checking.
